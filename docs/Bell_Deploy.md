# تجهيز نظام الجرس في بيئة جديدة — خادم واحد وأجهزة جرس متعددة

> هذا الدليل لتجهيز نظام الجرس من الصفر في مدرسة جديدة، أو لنقله إلى أجهزة جديدة.
> **آخر تحديث: 2026-10-21.** الدليل التقني الكامل: `docs/Bell.md`.

---

## 0) الصورة العامة

```
                         الإنترنت (https://5.iajaward.org)
                                   │  Cloudflare Tunnel «iajaward»
                                   ▼
   ┌──────────────────────────── شبكة المدرسة ────────────────────────────┐
   │                                                                     │
   │   [ الخادم ]  C:\Bell — المنفذ 8005 — واحد فقط للمدرسة كلها            │
   │      ▲              ▲                    ▲                          │
   │      │              │                    │   (عبر الإنترنت، أو عبر    │
   │      │              │                    │    الشبكة عند انقطاعه)    │
   │ [جهاز جرس 1]   [جهاز جرس 2]        [جهاز جرس 3]                     │
   │  المبنى الأول    المبنى الثاني        الروضة                         │
   │  BellPlayer.exe  BellPlayer.exe      BellPlayer.exe                 │
   │      │              │                    │                          │
   │  مضخّم/سمّاعات   مضخّم/سمّاعات        مضخّم/سمّاعات                   │
   └─────────────────────────────────────────────────────────────────────┘
        + تطبيقات الصفوف والمعلمين (Android / Desktop / المتصفح) بأكوادها
        + هاتف احتياطي (Termux) يستلم الموقع إن تعطل الخادم
```

| الجهاز | العدد | ماذا يُثبَّت عليه |
|---|---|---|
| **الخادم** | **واحد فقط** | Python + Git + نظام الجرس (`C:\Bell`) + نفق Cloudflare + Google Drive |
| **جهاز جرس** | واحد لكل مبنى أو جهاز صوت | `BellPlayer.exe` على كمبيوتر — **أو** علبة ESP32 بدون كمبيوتر (`docs/Bell_Hardware.md`) |
| هاتف احتياطي | اختياري | Termux (للطوارئ) |

- الخادم يمكن أن يكون هو نفسه جهاز الجرس في المبنى الذي يوجد فيه.
- كل أجهزة الجرس ترنّ **بتوقيت الخادم**، فترنّ معاً في اللحظة نفسها.
- كل جهاز جرس يحفظ الجدول والنغمات عنده، **ويرنّ حتى لو انقطع الإنترنت أو توقف الخادم**.

## 1) قبل البدء — ما تحتاجه

| البند | ملاحظة |
|---|---|
| كمبيوتر الخادم | Windows 10/11، يعمل دائماً، على شبكة المدرسة |
| كمبيوتر لكل جهاز صوت | Windows 10/11، موصول بالمضخّم (سلك AUX 3.5 ملم أو USB صوت) |
| حساب Google Drive | للنسخ الاحتياطية (مثل `G:\My Drive\RAS-Bell`) |
| رمز Cloudflare API | للنطاق `iajaward.org` (موجود في `.env` الخاص بـ ATT أو موقع الجائزة) |
| أداة الترخيص | `bell_license_key_generator.py` + `license_private_key.pem` — **عند المطوّر فقط** |

> ⚠ نفق Cloudflare `iajaward` يخدم كل الأنظمة (الجائزة، ATT، الجرس) ويوجّه كل عنوان إلى منفذه **على الجهاز الذي يعمل عليه النفق**.
> لذلك **خادم الجرس = الجهاز الذي يعمل عليه النفق**. لا تشغّل النفق نفسه على جهازين في الوقت نفسه.

## 2) إعدادات ويندوز (على الخادم وعلى كل جهاز جرس)

| الإعداد | أين |
|---|---|
| **منع السكون** | Settings ← System ← Power & sleep ← Sleep = **Never** (إطفاء الشاشة لا يضر) |
| **الدخول التلقائي** (أجهزة الجرس) | `Win + R` ← `netplwiz` ← إلغاء «Users must enter a user name and password» ← OK ← كلمة المرور مرتين |
| **السمّاعات** (أجهزة الجرس) | أيقونة الصوت ← Sound settings ← Output = المضخّم |
| تحديثات ويندوز | يُفضَّل ضبط «ساعات النشاط» على وقت الدوام حتى لا يُعاد التشغيل أثناءه |

> قفل الشاشة (`Win + L`) لا يوقف الصوت؛ **تسجيل الخروج يوقفه**.
> ساعة جهاز الجرس لا تهم — الرنين بتوقيت الخادم.

## 3) تجهيز الخادم

### أ) الطريقة السريعة (ملف واحد)
1. ثبّت **Google Drive for desktop** وسجّل الدخول، وتأكد من ظهور مجلد النسخ (مثل `G:\My Drive\RAS-Bell`).
2. شغّل نفق Cloudflare `iajaward` على هذا الجهاز (بطريقة موقع الجائزة).
3. نزّل **`install_bell.bat`**:
   `https://github.com/AcsVe/Bell/releases/download/apps/install_bell.bat`
4. كليك يمين ← **Run as administrator**.

ما يفعله تلقائياً:

| # | الخطوة |
|---|---|
| 1 | يثبّت Python 3.12 إن لم يوجد |
| 2 | يثبّت Git إن لم يوجد |
| 3 | ينزّل النظام إلى `C:\Bell` |
| 4 | الإعداد (`1_setup.bat`) — يطرح الأسئلة أدناه |
| 5 | «Restore now?» ← يسترجع أحدث نسخة من Drive (لمدرسة جديدة تماماً اختر `n`) |
| 6 | التشغيل مع ويندوز + نسخة كل ساعة + المراقب + فتح المنفذ 8005 لشبكة المدرسة، ثم الفحص |

أسئلة الإعداد:

| السؤال | الإجابة |
|---|---|
| Site address | **Enter** (`https://5.iajaward.org`) — أو عنوان المدرسة الجديدة |
| Backup folder | مجلد Drive، مثل `G:\My Drive\RAS-Bell` |
| Cloudflare API token | يُقرأ تلقائياً من `.env` الخاص بـ ATT إن وُجد، وإلا الصقه |
| Admin user / password | اسم المستخدم وكلمة المرور (8 أحرف على الأقل) |
| Copy all data from the old Render server? | **N** |

### ب) الطريقة اليدوية
```
git clone https://github.com/AcsVe/Bell.git C:\Bell
cd C:\Bell
1_setup.bat                 (الأسئلة نفسها)
restore_backup.bat          (إن كانت هناك بيانات سابقة في Drive)
3_autostart.bat             (كليك يمين ← Run as administrator)
bell_check.bat              (كمسؤول — يجب أن تظهر [OK])
```

### ج) التحقق
- `http://localhost:8005/admin` على الخادم.
- `https://5.iajaward.org/admin` من هاتف خارج شبكة المدرسة.
- `bell_check.bat` (كمسؤول): الموقع، والعنوان العام، وجهاز الجرس على هذا الجهاز.

## 4) إعداد البيانات (مدرسة جديدة فقط)

في لوحة الإدارة بالترتيب:
1. **المراحل والصفوف** ← المراحل وأيام الدوام ← الصفوف والشعب (تُولَّد الأكواد تلقائياً).
2. **برامج الجرس** ← التوقيتات (مثل «الصفوف 1+2») ← توزيعها على الصفوف لكل يوم.
3. **المعلمون** ← الأسماء وربطها بالشعب.
4. **الأكواد** ← طباعة أكواد الشعب والمعلمين للتطبيقات.
5. **الجرس المركزي** ← تبويب «النغمات لكل توقيت»: نغمة الحصة ونغمة الاستراحة لكل توقيت (14 نغمة عادية + 8 نغمات أطفال + رفع نغمات خاصة)، ومستوى الصوت، وأيام العطل.

> إن كانت هناك بيانات قديمة: «الإعدادات ← تنزيل كل البيانات» من النظام القديم ثم `import_render.bat` على الخادم الجديد بمسار الملف.

## 5) أجهزة الجرس (لكل مبنى)

### أ) في لوحة الإدارة — لكل جهاز
**الجرس المركزي ← تبويب «أجهزة الجرس» ← «إضافة جهاز جرس»**
1. الاسم (مثل «المبنى الثاني») ← **«إضافة وإنشاء مفتاح»** ← انسخ المفتاح (يظهر مرة واحدة).
2. في بطاقة الجهاز:
   - **يرنّ لـ:** «كل التوقيتات»، أو التوقيتات الخاصة بهذا المبنى فقط.
   - **مستوى الصوت:** العام أو خاص بهذا المبنى.
   - **حفظ**.

### ب) على كمبيوتر المبنى
1. نزّل **`BellPlayer.exe`** (إلى أي مكان، مثل Downloads):
   `https://github.com/AcsVe/Bell/releases/download/apps/BellPlayer.exe`
2. انقر عليه مرتين. يسأل:
   | السؤال | الإجابة |
   |---|---|
   | Install folder `[C:\BellPlayer]` | **Enter** (أو مجلد آخر — يُنشأ تلقائياً) |
   | Server address | **Enter** |
   | Player key | مفتاح هذا الجهاز من الخطوة (أ) |
   | Device fingerprint | تظهر — أرسلها للمطوّر (أو ولّد المفتاح بالأداة) |
   | License key | مفتاح الترخيص لهذه البصمة |
3. يجب أن يظهر: `[OK] running now, and starts with Windows`.
4. في مجلد التثبيت تجد ملفات جاهزة — **انقر مرتين بدل كتابة الأوامر**:

   | الملف | العمل |
   |---|---|
   | `1 - Setup (server, player key, license).bat` | إعادة الإعداد |
   | `2 - License (enter or renew).bat` | إدخال/تجديد الترخيص (يعرض البصمة) |
   | `3 - Status.bat` | الخادم، الجدول، الرنين التالي، الترخيص |
   | `4 - Network test.bat` | فحص الاتصال بالخادم |
   | `5 - Test speakers.bat` | نغمة على هذا الجهاز الآن |
   | `6 - Fingerprint.bat` | بصمة الجهاز |
   | `7 - Restart player.bat` | إعادة تشغيل المشغّل |
   | `8 - Stop player.bat` | إيقافه (لا يرنّ) حتى الدخول التالي أو «Restart» |
   | `9 - Show log.bat` | آخر سطور السجل |
   | `10 - Remove from Windows start-up.bat` | إزالته من بدء التشغيل |

> **التحديث لاحقاً:** نزّل الإصدار الجديد وانقر عليه مرتين ← «Update it with this version? (Y/n)» ← **Enter**. يستبدل النسخة المثبّتة ويعيد تشغيلها، والإعدادات والترخيص كما هي.

### ج) الترخيص (عند المطوّر)
1. ضع `bell_license_key_generator.py` و**`license_private_key.pem` الأصلي** في المجلد نفسه.
2. شغّل الأداة — يجب أن يبدأ المفتاح العام المطبوع بـ:
   `MFkwEwYHKoZIzj0CAQYIKoZIzj0DAQcDQgAE9hskm3ufgTN+cmD+Vhzv2w6OIiuw`
   (إن اختلف: الأداة لم تجد الملف الأصلي وأنشأت زوجاً جديداً — مفاتيحه مرفوضة.)
3. الصق البصمة ← اختر المدة (14 يوماً / 3 أشهر / سنة / دائم / عدد أيام) ← انسخ المفتاح.
4. لكل جهاز بصمة مختلفة ← مفتاح مختلف. بصمة BellPlayer تختلف عن بصمة برنامج التحليل home.py على الجهاز نفسه.
5. التجديد لاحقاً: `BellPlayer.exe --license` على الجهاز (يُقرأ خلال 30 ثانية دون إعادة تشغيل).

### د) التجربة
- لوحة الإدارة ← بطاقة الجهاز: **متصل**، الترخيص، «يرنّ بتوقيت الخادم».
- تبويب «مكتبة النغمات والتجربة» ← اختر النغمة ← ضع علامة على الأجهزة (المباني) المطلوبة أو «كل الأجهزة» ← **«رنّ الآن»** ← يرنّ خلال 15 ثانية.

## 7) الهاتف الاحتياطي (اختياري)

```bash
cd ~ && curl -sL https://github.com/AcsVe/Bell/archive/refs/heads/main.zip -o b.zip && \
  unzip -q b.zip -d btmp && mv btmp/Bell-main bell && rm -rf btmp b.zip && \
  sed -i 's/\r$//' ~/bell/standby/*.sh && bash ~/bell/standby/phone.sh setup
echo 'BELL_REMOTE="gdrive:RAS-Bell"' > ~/.bell_standby       # مجلد النسخ في Drive
bash ~/bell/standby/phone.sh configure
```
الأزرار: **BELL 1** تشغيل/إنهاء الطوارئ، **BELL 2** إرجاع للخادم، **BELL 3** الحالة، **BELL 4** تحديث، **BELL 5** رفع بيانات الهاتف.

## 8) الصيانة اليومية

| الحالة | ماذا تفعل |
|---|---|
| شيء لا يعمل | **`bell_check.bat`** (كمسؤول) على الخادم — يفحص ويصلح ويعرض الخطأ |
| تحديث النظام | `update.bat` على الخادم |
| تحديث BellPlayer | نزّل الجديد وانقر عليه مرتين ← «Update» ← Enter (الإعدادات والترخيص محفوظة في `bell_player.ini`) |
| إضافة مبنى | الخطوة 5 |
| استبدال جهاز جرس | «مفتاح جديد» في بطاقته + ترخيص جديد للجهاز الجديد |
| حذف جهاز | «حذف الجهاز» — يتوقف فوراً |
| تعطل الخادم | الأجهزة ترنّ من نسختها؛ للموقع والتطبيقات: زر BELL 1 على الهاتف |
| نقل الخادم لجهاز جديد | `backup_now.bat` على القديم ← `stop_autostart.bat` ← الخطوة 3 على الجديد (مع النفق) |
| انتهاء الترخيص | يتوقف رنين ذلك الجهاز وتظهر «غير مفعّل» في بطاقته ← ترخيص جديد |
