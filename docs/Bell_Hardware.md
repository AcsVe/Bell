# جهاز الجرس بدون كمبيوتر — ESP32 (القطع، التوصيل، التثبيت، البرمجة)

> علبة صغيرة تُوصل بمضخّم الصوت في المبنى **بدل الكمبيوتر وBellPlayer**.
> تتصل بالخادم عبر **Wi-Fi** (مزامنة تلقائية مثل BellPlayer)، أو تُبرمج من لوحة الإدارة عبر **Bluetooth** في المباني التي لا شبكة فيها.
> ترنّ من ذاكرتها وساعتها حتى دون إنترنت أو خادم. **آخر تحديث: 2026-10-22** — البرنامج `device-1.0`.
>
> ⚠ البرنامج مبني ومُختبر بالترجمة (compile) فقط — **لم يُجرَّب بعد على قطع حقيقية**. أول جهاز هو التجربة؛ أرسل ما يظهر على الشاشة أو في «الحالة» عند أي مشكلة.

---

## 1) ما هو «الجهاز الجاهز»؟

لا يوجد جهاز تجاري جاهز يعمل مع نظامنا (أجهزة «مؤقّت الجرس» التجارية مغلقة ولها برامجها الخاصة).
لكن **لا حاجة للحام**: كل القطع التالية تُباع **وحدات جاهزة بدبابيس**، وتُوصل بأسلاك توصيل (Dupont أنثى-أنثى) خلال 10 دقائق، ثم يُحمَّل البرنامج من لوحة الإدارة بسلك USB.
يمكن أيضاً أن يجمّعها أي محل إلكترونيات (هي 11 سلكاً) — أعطه الجدول في القسم 3.

## 2) القطع

| # | القطعة | المواصفة المطلوبة بالضبط | ملاحظة |
|---|---|---|---|
| 1 | **ESP32-S3-DevKitC-1** | **N16R8** (ذاكرة 16MB + PSRAM 8MB) | فيه Wi-Fi وBluetooth. يجب N16R8 — البرنامج مبني عليه |
| 2 | **PCM5102A** (وحدة I2S DAC) | الوحدة البنفسجية الشائعة بمخرج سماعات 3.5 ملم | مخرج صوت نقي إلى المضخّم |
| 3 | **DS3231** (وحدة ساعة RTC) | مع بطارية CR2032 | تحفظ الوقت عند انقطاع الكهرباء (ضرورية لوضع Bluetooth) |
| 4 | شاشة **SSD1306 OLED** 0.96″ I2C | 128×64، عنوان 0x3C | اختيارية: الوقت، الرنين التالي، الحالة |
| 5 | سلك صوت **3.5 ملم ← مدخل المضخّم** | (3.5 ملم ← 3.5 ملم، أو ← RCA، حسب المضخّم) | |
| 6 | شاحن **USB-C 5V 2A** + سلك USB-C | | التغذية + تحميل البرنامج |
| 7 | أسلاك Dupont أنثى-أنثى | 15 سلكاً تقريباً | |
| 8 | علبة بلاستيكية صغيرة | | اختيارية |
| 9 | **UPS صغير / باور بنك يدعم الشحن والتشغيل معاً** | | اختياري: يستمر الجرس عند انقطاع الكهرباء |

## 3) التوصيل

```
 ESP32-S3-DevKitC-1                  PCM5102A                    DS3231              OLED (اختيارية)
 ┌───────────────┐                  ┌──────────┐                ┌────────┐           ┌────────┐
 │ 5V ───────────┼──────────────────┤ VIN      │      ┌─────────┤ VCC    │   ┌───────┤ VCC    │
 │ GND ──────────┼──────────────────┤ GND      │      │ ┌───────┤ GND    │   │ ┌─────┤ GND    │
 │ GPIO5 ────────┼──────────────────┤ BCK      │      │ │ ┌─────┤ SDA    │   │ │ ┌───┤ SDA    │
 │ GPIO6 ────────┼──────────────────┤ LCK (LRCK)│     │ │ │ ┌───┤ SCL    │   │ │ │ ┌─┤ SCL    │
 │ GPIO7 ────────┼──────────────────┤ DIN      │      │ │ │ │   └────────┘   │ │ │ │ └────────┘
 │               │        GND ──────┤ SCK      │      │ │ │ │                │ │ │ │
 │ GPIO8 (SDA) ──┼──────────────────┼──────────┼──────┼─┼─┴─┼────────────────┼─┼─┘ │
 │ GPIO9 (SCL) ──┼──────────────────┼──────────┼──────┼─┼───┴────────────────┼─┼───┘
 │ 3V3 ──────────┼──────────────────┼──────────┼──────┴─┼─────────────────────┘ │
 │ GND ──────────┼──────────────────┼──────────┼────────┴───────────────────────┘
 └───────────────┘                  └────┬─────┘
                                   3.5mm ┴ ──→ مدخل المضخّم (AUX / LINE IN)
```

| من ESP32 | إلى | ملاحظة |
|---|---|---|
| **5V** | PCM5102A **VIN** | الوحدة فيها منظّم جهد — 5V أفضل لها |
| **3V3** | DS3231 **VCC**، OLED **VCC** | |
| **GND** | PCM5102A **GND** و**SCK**، DS3231 **GND**، OLED **GND** | **SCK في PCM5102A يُوصل بـ GND** |
| **GPIO5** | PCM5102A **BCK** | |
| **GPIO6** | PCM5102A **LCK** (أو LRCK / WS) | |
| **GPIO7** | PCM5102A **DIN** | |
| **GPIO8** | DS3231 **SDA** + OLED **SDA** | السلكان على الدبوس نفسه |
| **GPIO9** | DS3231 **SCL** + OLED **SCL** | |

**وحدة PCM5102A البنفسجية — وصلات اللحام الصغيرة على ظهرها (إن لم يخرج صوت):**
H1L (FLT) ← L، H2L (DEMP) ← L، **H3L (XSMT) ← H**، H4L (FMT) ← L. معظم الوحدات تأتي مضبوطة؛ أهمها XSMT = H (وإلا يبقى الصوت مكتوماً).

**التغذية:** شاحن USB-C في منفذ **USB** على ESP32 (أو منفذ UART — كلاهما يغذّي). لتحميل البرنامج استخدم منفذ **USB**.

## 4) تحميل البرنامج (مرة واحدة)

1. على جهاز الخادم: `update.bat` (يجلب ملفات البرنامج `static/firmware`).
2. على أي كمبيوتر فيه **Chrome أو Edge**: لوحة الإدارة ← **الجرس المركزي** ← تبويب «أجهزة الجرس» ← **«تثبيت البرنامج والبرمجة عبر Bluetooth»**.
3. وصّل ESP32 بسلك USB (منفذ **USB**) ← **«تثبيت / تحديث برنامج الجهاز»** ← اختر المنفذ (USB JTAG/serial) ← Install.
   - «Erase device?»: **نعم** في أول تثبيت؛ **لا** في التحديثات (تبقى الإعدادات والترخيص والنغمات).
   - إن لم يظهر المنفذ: اضغط زر **BOOT** مع **RST** ثم اترك RST، وأعد المحاولة.
4. بعد التثبيت تعرض الشاشة: الوقت، و«FP» = **بصمة الجهاز** (16 حرفاً).

## 5) التهيئة

### أ) في لوحة الإدارة
تبويب «أجهزة الجرس» ← **«إضافة جهاز جرس»** (مثل «الروضة») ← اختر توقيتاته ومستوى صوته ← حفظ.

### ب) عبر Bluetooth (Chrome على أندرويد، أو كمبيوتر فيه Bluetooth — لا يعمل على iPhone)
صفحة «جهاز جرس بدون كمبيوتر» ← «هذا الجهاز هو»: اختره ← **🔗 اتصال** ← اختر «Bell-xxxx».

| المبنى | الخطوة |
|---|---|
| **فيه Wi-Fi (الأفضل)** | اكتب اسم الشبكة وكلمة مرورها ← **«إرسال إعدادات Wi-Fi»** (يُنشأ مفتاح لهذا الجهاز ويُرسل تلقائياً). خلال دقيقة يتصل ويأخذ جدوله ونغماته وتوقيت الخادم، ويظهر «متصل» في بطاقته |
| **بلا شبكة** | **«إرسال الجدول والنغمات وضبط الوقت»** (دقيقة إلى ثلاث). **أعدها كلما تغيّرت الجداول أو النغمات أو العطل** |

**الترخيص:** البصمة تظهر في نافذة الحالة (`fingerprint`) وعلى الشاشة ← ولّد المفتاح بأداة الترخيص (نفس أداة BellPlayer) ← الصقه ← **«إرسال الترخيص»**.

**التجربة:** اختر نغمة ← **«رنّ الآن على الجهاز»**. ومع Wi-Fi يعمل أيضاً «رنّ الآن» العادي من تبويب التجربة.

### ج) بدون Bluetooth
اضغط زر **BOOT** على الجهاز **3 ثوانٍ** ← تظهر شبكة **«Bell-xxxx»** (كلمة المرور `bellsetup`) ← اتصل بها من الهاتف ← تفتح صفحة الإعداد (أو `192.168.4.1`) ← شبكة المدرسة، الخادم، **مفتاح الجهاز** (من بطاقته: «مفتاح جديد»)، الترخيص ← Save.
(تظهر هذه الشبكة تلقائياً أيضاً عند أول تشغيل لجهاز جديد لم يُهيّأ.)

## 6) كيف يعمل

| البند | السلوك |
|---|---|
| الوقت | **توقيت الخادم** مع كل اتصال (كل 15 ثانية)، ويُحفظ في DS3231. دون شبكة: DS3231 (ضُبط عبر Bluetooth) |
| الشبكة | يحاول آخر عنوان نجح ← عنوان الخادم على شبكة المدرسة ← العنوان العام |
| الجدول والنغمات | محفوظة في ذاكرة الجهاز؛ يرنّ منها دون إنترنت أو خادم |
| بعد إعادة التشغيل | يكمل وحده؛ لا يعيد رنيناً فاته أثناء الإطفاء |
| الترخيص | يُفحص يومياً؛ دونه أو بعد انتهائه لا يرنّ، وتعرض الشاشة «NO LICENSE» |
| النغمات المرفوعة | **WAV فقط** (16-بت). نغمات MP3 لا تُشغَّل على الجهاز — ارفعها WAV إن كانت لمبنى فيه جهاز ESP32 |
| الشاشة | الوقت، التاريخ، الرنين التالي، Wi-Fi، الترخيص، البصمة |

## 7) مشاكل شائعة

| المشكلة | الحل |
|---|---|
| لا صوت | سلك 3.5 ملم في مدخل المضخّم الصحيح؛ **SCK ← GND** و**XSMT = H** في PCM5102A؛ الصوت في بطاقة الجهاز ليس منخفضاً |
| صوت مشوّه أو بطيء | تأكد من BCK/LCK/DIN على 5/6/7 بالترتيب |
| «time not set» | لم يتصل بالخادم ولم يُضبط عبر Bluetooth؛ أو DS3231 غير موصولة/بطاريتها فارغة |
| «NO LICENSE» | أرسل الترخيص؛ تأكد أن المفتاح لبصمة **هذا** الجهاز (FP على الشاشة) |
| لا يظهر في Bluetooth | Chrome فقط (ليس iPhone)؛ فعّل الموقع (Location) على أندرويد؛ أعد تشغيل الجهاز |
| «server refused the player key» | أنشأت مفتاحاً جديداً للجهاز ← أرسل إعدادات Wi-Fi مرة أخرى (مع «إنشاء مفتاح جديد») |
| بطاقة الجهاز «غير متصل» في وضع Bluetooth | طبيعي — يُحدَّث فقط عند البرمجة عبر Bluetooth |

## 8) للمطوّر
